# Data Cleaning Project

This is my Python data cleaning project. In this project, I worked on a sales dataset and prepared it for further analysis.

I used Python and Pandas to check the data and fix common data quality problems.

## What I Did

- Loaded the raw sales data
- Checked the rows and columns
- Checked missing values
- Checked duplicate records
- Converted the order date into the correct format
- Filled missing values
- Removed duplicate records
- Saved the cleaned data

## Tools Used

Python, Pandas, VS Code, Git and GitHub.

## Project Files

The raw dataset is available in the `data` folder.

The Python cleaning code is available in the `src` folder.

The cleaned dataset is saved in the `output` folder.

The data quality report is available in the `reports` folder.

## Conclusion

This project helped me understand how to inspect, clean and prepare a dataset using Python and Pandas. The cleaned data can now be used for further analysis.
