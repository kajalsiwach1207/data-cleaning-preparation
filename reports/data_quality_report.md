# Data Quality Report

Project: Data Cleaning and Preparation

### Overview

I worked on a sales dataset to clean and prepare it for further analysis. I used Python and Pandas to inspect the data and identify common data quality problems.

### Cleaning Steps

- Checked missing values and handled them appropriately.
- Removed extra spaces and standardized city names.
- Converted order dates into a proper date format.
- Converted quantity and unit price into numeric data types.
- Checked for duplicate records.
- Saved the cleaned dataset as 'cleaned_sales_data.csv'.

### Tools Used

- Python
- Pandas
- VS Code

### Learning

This project helped me understand how to inspect raw data, identify cleaning problems, and prepare a reliable dataset for analysis.

## Change Log

During the cleaning process, I found a few data quality issues in the sales dataset. I checked each issue and applied the required changes.

- **Missing values:** I checked the columns for missing values and filled them wherever necessary.
- **Duplicate records:** I checked for duplicate rows and removed the duplicate records.
- **Date format:** The Order Date column had different date formats, so I converted it into a consistent date format.
- **Data types:** I checked the data types of the columns and converted the date column into the correct format.
- **Final checks:** After cleaning the data, I checked the missing values and duplicate records again to make sure the cleaning was successful.

## Final Result

The cleaned dataset was saved as `cleaned_sales_data.csv` in the output folder. The data is now better organized and ready for further analysis.
